# Brillo_Total
Desarrollé una web moderna, con diseño atractivo y distribución pensada para la comodidad del usuario, integrando endpoints funcionales. El proyecto busca ofrecer excelencia en pulimiento y mantenimiento de pisos de mármol y granito, mostrando la calidad y experiencia del servicio. Actualmente se trabaja en mejoras para su próximo lanzamiento.
